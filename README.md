# DrazenAI

AI pomoćnik za Linux, mreže i bezbednost — sa lokalnim Ollama modelima.

## 🚀 Funkcije

- 🤖 **AI chat** — preko Ollama (Llama, DeepSeek, Mistral, Qwen)
- 📁 **Organizacija fajlova** — po kategorijama
- 🔎 **Pretraga fajlova** — po imenu
- 📄 **Analiza teksta** — reči, linije, karakteri
- 📊 **Sistem info** — disk, Python, home
- 🧹 **Veliki fajlovi** — pronađi fajlove > 100 MB
- 🖥️ **Shell komande** — sa safety filterom
- 📋 **Activity log** — sve akcije se loguju

## 📋 Zahtevi

- Python 3.10+
- Ollama (https://ollama.ai)
- Linux (testirano na Fedora 44)
